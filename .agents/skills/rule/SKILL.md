# Rule

This skill is a special case of the `simple` skill. Read
`~/.agents/skills/simple/SKILL.md` and apply its requirement to the whole
session. Skip its confirm-and-wait step: continue directly with the ruling.

You are the first pass: write the draft. A fresh session rewrites it afterwards
through the ruling edit, so write the ruling as if it were final rather than
leaving notes for that pass.

The arguments name the round transcript and audit report.
Read `references/workflow.md` completely and follow it.
